# Car Evaluation App

This project is a desktop application built with Python using the `tkinter` library for GUI. It provides a simple interface for importing data, evaluating machine learning models, visualizing feature importances, and comparing model performance over time.

## Features

- 📂 **Import Data**: Load dataset for car evaluation.
- 📊 **Model Evaluation**: Run and display evaluation metrics for the trained model.
- 🔍 **Feature Importances**: Visualize which features are most influential in the model.
- ➕ **Add Model Evaluation Data**: Add new evaluation results for tracking performance.
- 📈 **Change in Model Evaluation**: Compare current model performance with previous versions.

## Technologies

- Python
- Tkinter (GUI)
- Scikit-learn
- Matplotlib & Seaborn
- Jupyter Notebook for development

## How to Run

1. Make sure you have Python installed (preferably 3.8+).
2. Install required packages:
   ```bash
   pip install pandas scikit-learn matplotlib seaborn
   ```
3. Run the notebook or convert it to `.py` script:
   ```bash
   jupyter notebook
   ```
4. Click "Run" to launch the GUI.
